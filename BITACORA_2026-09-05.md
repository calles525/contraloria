## 3. Tarea nueva: documentos requeridos como input tipo file

Solicitud del usuario: los documentos requeridos deben ser campos de carga de archivo y los archivos deben guardarse.

### Base de datos
- Migración 004 aplicada (`db/migraciones/004_solicitud_requerimientos_archivo.sql`):
  - Columnas `archivo_nombre` y `archivo_ruta` en `solicitud_requerimientos`.

### Backend
- Dependencia `multer` instalada en el paquete `contraloria-backend`.
- `backend/src/middlewares/subirArchivo.middleware.js`:
  - Guarda en `backend/uploads/solicitudes/{solicitudId}/` con nombre seguro.
  - Extensiones permitidas: pdf, png, jpg, jpeg, webp, doc, docx, xls, xlsx.
  - Tamaño máximo 10 MB; errores traducidos a respuestas 400.
- Servicio: `adjuntarArchivoRequerimiento` (marca cumplido = 1 y guarda el archivo), `obtenerArchivoRequerimiento` (descarga, permite incluso en estados terminales) y `quitarArchivoRequerimiento` (elimina el archivo y deja cumplido = 0).
- Controlador y rutas:
  - POST `/api/solicitudes/:id/requerimientos/:reqId/archivo` (multipart, campo `archivo`).
  - GET `/api/solicitudes/:id/requerimientos/:reqId/archivo` (descarga).
  - DELETE `/api/solicitudes/:id/requerimientos/:reqId/archivo` (quitar).
- Reglas de negocio: no se permite adjuntar ni quitar archivos en solicitudes cerradas (VALIDADDA o RECHAZADA); el reemplazo elimina el archivo anterior.
- `.gitignore` del backend: `uploads/` excluida.
- Corrección aplicada: faltaba importar `fileURLToPath` en el servicio (dejó el backend caído); se relanzó el servidor y quedó operativo.

### Verificación del flujo de archivos por API (paso a paso)
1. Creación de solicitud de prueba SOL-2026-0003 (CLIENTE, 2 requerimientos, cumplido = 0).
2. Subida de archivo al requerimiento "RIF": respuesta OK, archivo `documento-prueba.pdf`, cumplido = 1, ruta `uploads/solicitudes/3/archivo-...pdf`.
3. Descarga del archivo: HTTP 200.
4. Quitar archivo: cumplido = 0, archivo vacío.
5. Eliminación de la solicitud de prueba (HTTP 204). Sin residuos.

### Frontend
- `types/solicitudes.ts`: `Requerimiento` ahora incluye `archivo_nombre` y `archivo_ruta`.
- `services/solicitudes.ts`: `subirArchivoRequerimiento` (FormData), `quitarArchivoRequerimiento` y `descargarArchivoRequerimiento` (blob + token, nombre desde Content-Disposition).
- `CrearSolicitudModal.tsx`: cada documento requerido es un input tipo file (botón "Adjuntar", muestra el nombre del archivo elegido y botón "Quitar"). Al adjuntar, el requerimiento se marca cumplido automáticamente. Al guardar, la página crea la solicitud y sube los archivos de inmediato.
- `GestionarSolicitudes.tsx`: manejadores para adjuntar, quitar (con confirmación) y descargar documentos desde el modal de gestión.
- `GestionarSolicitudModal.tsx`: por cada documento muestra estado (cumplido/pendiente), botón "Descargar" si hay archivo, y mientras la solicitud no esté cerrada permite adjuntar, reemplazar o quitar el archivo.

### Verificación final
